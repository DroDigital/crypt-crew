CRYPT CREW
==========
A 1-4 player local co-op dungeon roguelite. Dive into the crypt, clear rooms of
skeletons, pick relics, beat the Bone King. Reviving a downed friend costs gold
from the shared purse.

HOW TO LAUNCH
-------------
Windows : unzip, open the folder, double-click CryptCrew.exe.
          If SmartScreen warns about an unknown publisher: More info > Run anyway.
macOS   : unzip and move "Crypt Crew.app" anywhere (e.g. Applications).
          If the build is not notarized, macOS will refuse the first launch:
          right-click (or Control-click) the app > Open > Open,
          or System Settings > Privacy & Security > "Open Anyway".
Linux   : tar xzf the archive, then run ./CryptCrew from the folder.
          Optional: copy crypt-crew.desktop to ~/.local/share/applications
          and crypt-crew.png to ~/.local/share/icons to get a menu entry
          (edit Exec= to the full path of CryptCrew).

Keep CryptCrew next to its assets/ and data/ folders.

CONTROLS
--------
                 Gamepad (Xbox / PlayStation / Switch Pro)   Keyboard + mouse
Join / Start     A or Start                                  Enter
Move             Left stick                                  WASD
Aim              Right stick (idle = auto-aim)               Mouse
Attack           X / Square / Y(Switch)  or RT               Left mouse
Special          Y / Triangle  or LT                         Right mouse
Dodge            A / Cross  or RB                            Space
Interact/Revive  B / Circle  (hold)                          E (hold)
Pause            Start / Options / +                         Esc

Up to 4 gamepads plus one keyboard+mouse player. Press A/Start (or Enter) in
the lobby to join, pick a class, ready up.

Settings are saved per user:
  Windows: %APPDATA%\CryptCrew
  macOS:   ~/Library/Application Support/CryptCrew
  Linux:   $XDG_DATA_HOME/crypt-crew (or ~/.local/share/crypt-crew)
